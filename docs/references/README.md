# References

<!-- cspell:words Crosspoint -->

Research and technical references for font rendering on low-bit-depth displays.

- [Font evaluation](font-evaluation.md): sizing recommendations and rendering evaluation methods.
- [Panel frame formats](panel-frame-formats.md): binary bit order, grayscale packing, and specimen viewer headers.
- [Reflective display model](../reflective-display-model.md): appearance palettes, presets and sources for screen
  previews.
- [Font diagnostics](font-diagnostics.md): capture and comparison tools using the current Rust generator.
- [Filtered-wall spacing](filtered-wall-spacing.md): Hu–Hersch measurement, newer alternatives and bounded adaptation.
- [Delivered Hu/Hersch model](hu-hersch-delivered-model.md): published depth parameters, cavity construction and
  delivered calibration with explicit adaptation boundaries.
- [Hu/Hersch construction order](hu-hersch-construction-order.md): cavity supports, measurement-window clipping and
  calibration effects distinguished from local wall corrections.
- [Shared-target density calibration](shared-target-density-calibration.md): source-designed reference targets,
  raster-reference bias and limits of reference-pair density.
- [Fixed-alphabet spacing density](fixed-alphabet-spacing-density.md): source-score and source-origin calibration arms,
  continuous conservation and post-placement limits.
- [Stem/curve reference experiment](hersch-stem-curve-reference-experiment.md): six source-master standards and the
  unresolved feature-classification gate.
- [Perceptual spacing reassessment](optical-spacing-perception-reassessment.md): original paper mechanisms and current
  implementation departures.
- [Pair-spacing alternatives](optical-spacing-pair-models.md): two-dimensional and whole-shape models, evidence limits
  and the recommended reference experiment.
- [YinYangFit feasibility](yinyangfit-feasibility.md): incomplete current scoring code, historical training prototype
  and the unmet calibrated-reproduction gate.
- [YinYangFit geometric alternatives](yinyang-geometric-alternatives.md): executable pair-selection paths, manual
  calibration requirements and browser adaptation limits in the cited geometric tools.
- [YinYangFit learned alternatives](yinyang-learned-alternatives.md): recovered Cozens checkpoints, inference-contract
  mismatches and the unresolved delivered-bitmap/browser gates.
- [CounterSpace cavity classifier](counterspace-cavity-classifier.md): signed-jump behavior, raster-stair sensitivity
  and limits of the intensity repair.
- [Optical pair-spacing target](optical-pair-spacing-target.md): shared-target mechanisms, bitmap adaptations and limits
  of pair whitespace estimates.
- [Upright stem consistency](upright-stem-consistency.md): paper-backed approaches to shared borders, local stroke
  widths and font-wide weight decisions.
- [Font converters](font-converters.md): front-page comparison methodology and Crosspoint gray-level handling.
- [Font assets](../../fonts/README.md): font identities, embedded declarations, and variation axes.
- [Papers](papers/): original PDFs, Markdown extractions, figures, and source metadata.
- [Research corpus](papers/CORPUS.md): source coverage and relevance to this project.
- [Specs](specs/): local OpenType and TrueType specification copies.
- [VisualTrueType](VisualTrueType/): upstream compiler source and documentation.
