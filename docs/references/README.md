# References

Research and technical references for font rendering on low-bit-depth displays.

- [Font evaluation](font-evaluation.md): sizing recommendations and rendering evaluation methods.
- [Panel frame formats](panel-frame-formats.md): binary bit order, grayscale packing, and specimen viewer headers.
- [Reflective display model](../reflective-display-model.md): appearance palettes, presets and sources for screen
  previews.
- [Font diagnostics](font-diagnostics.md): capture and comparison tools using the current Rust generator.
- [Font assets](../../fonts/README.md): font identities, embedded declarations, and variation axes.
- [Papers](papers/): original PDFs, Markdown extractions, figures, and source metadata.
- [Research corpus](papers/CORPUS.md): source coverage and relevance to this project.
- [Specs](specs/): local OpenType and TrueType specification copies.
- [VisualTrueType](VisualTrueType/): upstream compiler source and documentation.
