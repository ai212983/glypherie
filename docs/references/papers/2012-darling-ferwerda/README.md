## Review scope

This seven-page author-hosted manuscript has no printed proceedings folios. Page labels identify the unnumbered
manuscript; the citation gives the published proceedings pagination. The rendering, display and limitations sections
were inspected. Exact multispectral basis reproduction and fitted material parameters are not adopted by the project.
All three numbered equations and Table 1 were visually checked and restored. All seven numbered figures have image
coverage. Remaining prose and inline notation are machine OCR; see extraction provenance for the review boundary.

The [reflective display model](../../../reflective-display-model.md) describes the current appearance-preview scope.
