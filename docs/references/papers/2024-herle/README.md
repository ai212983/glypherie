## Review scope

The 34-page published review uses article-page labels 020901-1 through 020901-34. Sections 2, 4 and 5 were inspected for
optical metrics and electrophoretic/LCD mechanisms. The generic ambient-contrast expression and a luminance example
labeled in lux in §2.1 are not adopted as the project model. The survey does not calibrate our named devices. See
extraction provenance for checked mathematics and remaining transcription uncertainty.

The [reflective display model](../../../reflective-display-model.md) describes the current appearance-preview scope.
