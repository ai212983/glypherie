## Review scope

The scanned publisher version has eight pages. Equations (1)–(12) and Table 1 were visually checked and restored through
reproducible review patches. All numbered figures have image coverage. Most inline notation and prose remain machine
OCR; some right-edge text is clipped in the source scan. Consult the unchanged PDF for exact interpretation. The authors
label their fitted historical parameters illustrative; they are not measurements of our target devices.
