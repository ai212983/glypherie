How spacing is selected

For each pair, the model tests every whole-pixel position in its ordered range, from the tightest forward step to the widest step its fields can still support. It uses the supported position whose score is closest to the target, skipping overlaps and unsupported steps; with no supported position it keeps the font's spacing.
