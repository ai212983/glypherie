YinYangFit-inspired interactive spacing feasibility

Isolated experiment: three global controls rescore integer pair placements on delivered Mono and Gray cells. Glyph bitmaps never change; only whole-pixel origin steps move. Face and corner contact is permitted; occupied-cell overlap is forbidden and recorded.

Not optically approved. Mechanical evidence only. Every slider position is an exactly precomputed setting (sliders snap to evaluated grid points; nothing is interpolated). This page is a fixed precomputed grid over fixed captured datasets and words: no live scorer, no arbitrary text. Boundary minima and invalid candidates are shown, not hidden. Target cohesion

Project-hypothesis set-point for the integer search (adapted from Electric Bubble). Low values loosen spacing; high values tighten it. Endpoints can saturate at the candidate-domain edge; the table flags those boundary minima.

Interaction reach (px)

Larger reach weights distant ink more; smaller reach localizes the interaction to the gap. A radial knee in pixels, not V1 feature-scale filter weighting; the stored field keeps the compatible name feature_scale.

Proximity falloff

Radial decay shape: steeper falloff (larger q) weights near ink more sharply. Not an independently implemented crowding penalty.

Model, sources and departures

  • Nearest-distance probe within YinYangFit feasibility work: a specifically sourced Electric Bubble-inspired project hypothesis, not a reproduction of YinYangFit's oriented model and not proof of its approach.
  • Radial factors r^-q and r^-(q+1) with q near 2 borrow only the field shapes from the direct approximation (primary reference). No oriented convolution kernels, no ratio distance estimator, no multiscale V1C responses and no multiple contour support are implemented; those are explicit departures, and the single-nearest-sample rule ignores support multiplicity and orientation.
  • Nearest-sample coverage takes each background point's nearest ink sample's coverage with no integration over support; the regularized power kernel g/(1+(r/scale)^q) is finite at r = 0 and claims no singularity treatment. The four same-named pair-field diagnostics record this probe's behavior and do not reproduce upstream oriented quantities.
  • Attention-normalized mean interaction and the integer search toward a desired value follow Electric Bubble's browser prototype (superseded by YinYangFit). Using that normalization as the aggregation rule is an explicit project hypothesis, not an upstream specification; the JAX notebook defines no scalar reduction.
  • Equidistance and opposing-gradient attention factors follow Electric Bubble; the vertical-position factor, which upstream parses but does not apply, is omitted here too. Single-scale evaluation is an acknowledged compromise from the distance-transform alternative, which assumes one dominant grouping scale.
  • Gray coverage is used linearly as delivered (3-bit codes 0-7 mapped to 0-1) without thresholding, and exported to the page without rounding. Display mapping is a documented assumption, not a claim about luminance.
  • Tie-break toward the metric step, the five-candidate domain (metric +/- 2 px), and the metric-nearest fallback are project choices, recorded per pair. The minimizing set anchors at the global valid minimum, then admits every valid candidate within tolerance; selection mirrors that rule exactly.
  • Word layouts distinguish three policies: metric-rounded pair search centers, the experiment's cumulative whole-pixel word layout, and the captured-source fractional word baseline shown beside it.
