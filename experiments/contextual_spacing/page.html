Font calibration targets
Each model reports its reference measurements and parameter provenance at the captured axes. Hu/Hersch uses published depth coefficients (US5768490A). Shared-reference spacing measures delivered bitmap cells; Hu source-relative compensation measures source outlines and delivered cells with the same filters to preserve each pair’s designed gap. CounterSpace fits the selected source or delivered calibration geometry at designed reference placements and scores delivered bitmap cells; the earlier comparison methods use source outlines. The comparison models’ 00 numeral anchor is experimental. Unsupported pairs and unavailable references keep metric placement.
