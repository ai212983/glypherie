About this experiment

This page tests two separated controls. Optical correction blends each pair's original placement toward a fixed method result; letter spacing adds whole pixels between letters. Letter shapes never change; only the space between letters moves, in whole pixels.

Grayscale currently reuses spacing corrections from the black-and-white analysis while keeping the original grayscale letter shapes.

The comparison keeps the original delivered placement beside the adjusted placement. Details of the method, its sources and its limits are in the prototype note.
